## 📖 Hakkında

Ders Takip, öğrenci derslerini planlamak, takip etmek ve yönetmek için geliştirilmiş bir PWA uygulamasıdır.

## 🎯 Özellikler

- 👨‍🎓 Öğrenci Yönetimi
- 📅 Ders Planlama
- 💵 Aylık Kazanç Takibi
- 📊 Deneme Sınavları
- 🔍 Karşılaştırma
- 🧠 Yapay Zeka Analizi
- 📱 WhatsApp Entegrasyonu
- 🔔 Bildirim Sistemi
- 📡 Çevrimdışı Çalışma
